**诚实性核对 - 今天真正能运行的内容：** 一个 Rust 库和一个命令行，计算通电铜走线的温升（焦耳热，电阻随温度增大，对流散热），以及串联与并联热阻网络上的温升。结果只有在带有假设、边界条件、材料、不确定度、局限和有效范围时才会被接受；过热或不收敛的情形不给出任何数值。所有这些只用自身测试生成的算例和闭式公式的值运行过；没有与求解器或测量对比。尚不存在：使用仿真域的损耗、与机械几何的耦合，以及与测量的对比。

> **安全（safety）与信息安全现状：** 本仓库刚刚起步，不是安全系统（safety）。这里写的任何内容都不能取代机床及其控制器的限位、联锁和急停。

## 🎯 概述

* **已有内容：** 一个无窗口的库和命令行，计算走线的发热（`trace`）、热网络上的温升（`network`），并检查结果是否带有全部条件（`check`）。**计划中：** 仿真域的热源、与几何的耦合以及与测量的对比。

## 🧩 在 EH3D 中的角色

EH3D-THERMAL-LAB 是 EH3D Fabrication Suite 的 PHOENIX 系列的一部分。它将做什么、暂时不做什么、需求以及与其他仓库的关系都写在 `docs/` 文件夹中。

## 🚀 快速开始

需要 Python 3.10 或更高版本；无需安装任何东西。

```bash
python -I tools/ci_validate.py
python -I tools/make_architecture.py --check
python -I tools/make_structure.py --check --readmes
python -I -m unittest discover -s tools -p "test_*.py"
```

## 🧪 测试

基础部分有 3 个测试（`python -I -m unittest discover -s tools -p "test_*.py"`），并且都通过。CI 运行仓库检查、图片检查和这些测试。
