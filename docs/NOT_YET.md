# EH3D-THERMAL-LAB: not yet

Good ideas that are not in the current version. Writing them here keeps anybody from implementing them early or twice.

| Idea | Why not yet | Revisit when |
|---|---|---|
| Co-simulation with electromagnetic solvers | Stage 3; it needs stages 1 and 2 and the RF tooling | stage 2 is done |
| Dynamic heat maps during RF simulations | It needs the RF tooling | stage 3 starts |
| Stress from the mismatch of thermal expansion between board and chassis | It needs the geometry of both and a model of the materials that is not written | the coupling with the geometry exists |
| A solver for two or three dimensions | Stage 1 is analytic by decision; a solver needs a choice nobody has made | stage 2 starts |
| A task kind for the server | The server has no kind of task for a thermal case yet | the server accepts tasks from the engines |
